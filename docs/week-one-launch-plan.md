# FrontDeskWise: first-week launch plan

The goal of week one is not to complete a general-purpose chatbot platform. It is to create a repeatable proof-of-value loop for one vertical, then put that loop in front of real businesses.

## The wedge

Start with appointment- and enrollment-driven local businesses where a question naturally leads to an action:

1. Swim schools and aquatic programs.
2. Salons and medspas.
3. Kids activity centers and daycares.

The first vertical should be swim schools because the workflow is concrete: age, level, location, availability, registration.

## Days 1–2: product loop

- Publish the landing page with one CTA: `Generate my AI front desk`.
- Accept a business URL and create a sandbox demo slug.
- Crawl or manually seed three public demo businesses.
- Show grounded answers, sample questions, lead capture, and a booking CTA.
- Record unanswered questions as knowledge gaps.

## Days 3–4: proof and outreach

- Generate 25 personalized demos from real local-business websites.
- Send a short founder-led message with the demo link, not a generic pitch.
- Ask for a 15-minute review of three conversations.
- Track URL entered, demo opened, first question, lead captured, and reply received.

## Days 5–7: conversion

- Add a simple install path: one script snippet plus a booking/lead destination.
- Offer a founding plan with concierge setup and a clear monthly price.
- Publish one vertical landing page and one public demo per vertical.
- Turn every unanswered question into a small knowledge-base improvement.

## Metrics

- URL → demo created: 80%+
- Demo created → first question: 50%+
- Demo opened → owner reply: 10%+
- Activated business → first lead: under 24 hours
- First answer grounded in source content: 95%+

## Do not build in week one

Voice, WhatsApp, a workflow canvas, a large integration catalog, multi-agent orchestration, or a full billing system. The first loop is:

```text
URL → agent → correct answer → lead → booking
```
